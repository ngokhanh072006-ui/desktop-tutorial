PHAN MEM QUAN LY SINH VIEN - JAVA VS CODE

CONG NGHE
- Java 17
- Java Swing
- MySQL
- JDBC
- Maven

CAC CHUC NANG
1. Quan ly sinh vien: them, sua, xoa, tim kiem theo ma hoac ho ten.
2. Quan ly lop: them, sua, xoa, tim kiem lop.
3. Quan ly diem: them, sua, xoa, tim kiem ket qua theo ma sinh vien.

CAI DAT VA CHAY
1. Cai JDK 17 tro len.
2. Cai Visual Studio Code va extension "Extension Pack for Java".
3. Cai MySQL Server va MySQL Workbench.
4. Mo MySQL Workbench, ket noi local MySQL.
5. Mo file database.sql va chay toan bo noi dung de tao database quanlysinhvien.
6. Mo DB.java va sua USER/PASSWORD theo tai khoan MySQL cua ban.
7. Mo thu muc du an trong VS Code.
8. Cho Maven tai MySQL Connector.
9. Mo src/main/java/qlsv/Main.java va bam Run.

LUU Y
- Can bat MySQL Server truoc khi chay Java.
- Port mac dinh la 3306.
- Tai khoan mac dinh trong code la root, mat khau de trong. Hay sua PASSWORD neu may ban co mat khau.
- Them lop truoc khi them sinh vien co ma lop tuong ung.
- Khi xoa sinh vien, diem cua sinh vien do cung bi xoa theo.
